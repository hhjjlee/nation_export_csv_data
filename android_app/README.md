# 한글자막 플레이어 — 안드로이드 (갤럭시 S25용)

[데스크톱 버전](../subtitle_player)과 같은 기능을 하는 안드로이드 앱입니다. 동영상을 **재생하면 폰 안에서 음성을 인식해 한국어 자막을 만들고, 화면에 보여 주면서 `.srt` 파일로 자동 저장**합니다.

- 🎬 **재생과 동시에 자막 생성**: 지금 보고 있는 위치부터 먼저 만들고, 다른 곳으로 이동하면 그 위치부터 다시 우선 처리합니다.
- 📱 **음성 인식은 폰에서 직접**: [whisper.cpp](https://github.com/ggml-org/whisper.cpp)(OpenAI Whisper)를 폰에서 실행합니다. 영상은 어디로도 업로드되지 않습니다.
- 🌏 **원본 언어 자동 감지**: 영어, 일본어, 중국어 등 99개 언어. 한국어 영상은 번역 없이 한국어 자막을 만듭니다.
- 🇰🇷 **번역**: 구글 번역(무료, 키 불필요) 또는 Claude AI(문맥을 고려한 자연스러운 번역, API 키 필요).
- 💾 **자동 저장 · 이어서 만들기**: 몇 초마다 저장하고, 중간에 닫아도 다음에 열면 남은 부분만 만듭니다.
- ✏️ **자막 목록**: 누르면 그 장면으로 이동, 길게 누르면 번역을 고칠 수 있습니다.

## 설치 (APK 직접 설치)

1. GitHub 저장소의 **Actions** 탭 → **Android APK (한글자막 플레이어)** → 가장 최근의 초록색(성공) 실행을 엽니다.
2. 아래쪽 **Artifacts**에서 `KoSubPlayer-apk`를 내려받아 압축을 풀면 `KoSubPlayer-xxxxxxx.apk`가 있습니다. (폰 브라우저에서 GitHub에 로그인해 바로 받아도 됩니다.)
3. 갤럭시에서 **내 파일**로 APK를 열고 설치합니다.
   - "출처를 알 수 없는 앱" 설치를 허용하라는 안내가 나오면 **설정 → 이 출처 허용**을 켭니다.
   - Play 프로텍트 경고가 나오면 **세부정보 → 무시하고 설치**를 누릅니다. 개인 빌드라 Play 스토어에 등록된 서명이 없어서 나오는 경고입니다.
4. 새 버전도 같은 방법으로 설치하면 기존 앱 위에 덮어 설치됩니다(설정과 만든 자막은 유지).

## 사용법

- **동영상 열기**: 앱의 *동영상 열기* 버튼, 또는 갤러리/내 파일에서 동영상을 *공유 → 한글자막 플레이어* 혹은 *다른 앱으로 열기*.
- **처음 한 번**: 음성 인식 모델(기본 `small`, 약 190MB)을 내려받습니다. Wi-Fi를 권장합니다.
- **재생 화면**: 화면을 한 번 누르면 위쪽에 상태와 진행 막대가 나옵니다. 막대의 **초록색은 자막이 만들어진 구간**, **노란색은 지금 만들고 있는 구간**입니다.
- **⋮ 메뉴**: 자막 만들기 멈추기/이어서 만들기, 번역 다시 하기(설정을 바꾼 뒤), 처음부터 새로 만들기, 원문 함께 표시, 자막 저장 위치, 설정.
- **가로로 돌리면** 전체 화면으로 재생합니다. 이어보기 위치는 자동으로 기억합니다.

### 자막 파일 저장 위치

| 설정 | 저장 위치 |
|---|---|
| 기본값 | 내장 메모리 `Download/KoSubPlayer/영상이름.ko.srt` |
| *설정 → 자막 저장 폴더*에서 동영상이 있는 폴더 선택 | 그 폴더에 `영상이름.ko.srt` → MX Player, VLC 등 다른 플레이어가 자막을 자동으로 찾습니다 |

원어 자막(`영상이름.en.srt` 등)도 함께 저장하고(설정에서 끌 수 있음), 원하면 이중 자막(`영상이름.ko+en.srt`)도 저장합니다.

## 설정

| 항목 | 설명 |
|---|---|
| 인식 모델 | `small`(기본, 균형) · `tiny`/`base`(빠름) · `medium`/`large-v3-turbo`(정확, 느림). 자막이 재생 속도를 못 따라가면 작은 모델을 고르세요 |
| 원본 언어 | 기본은 자동 감지. 알고 있으면 지정하는 편이 더 정확합니다 |
| 번역 방식 | 구글 번역(무료) / Claude AI / 번역 안 함 |
| Claude | [console.anthropic.com](https://console.anthropic.com/)에서 발급한 API 키, 모델(기본 Claude Opus 5.5), 번역 방식. 요청이 안전 정책 때문에 거절되면 서버가 대체 모델로 자동 재시도하도록(`fallbacks: "default"`) 설정되어 있습니다 |
| 자막 크기·배경, 원문 함께 표시 | 화면 표시 방식 |

## 알아 두실 점

- 음성 인식은 폰의 CPU로 돌기 때문에 처리하는 동안 배터리를 많이 쓰고 폰이 따뜻해질 수 있습니다.
- 자막 만들기는 재생 화면이 열려 있는 동안 진행됩니다. 다른 앱으로 가면 멈출 수 있지만, 다시 열면 이어서 만듭니다.
- 재생은 기기가 지원하는 코덱으로 합니다. 일부 오디오 형식(DTS 등)은 기기에 디코더가 없어 자막을 만들 수 없을 수 있습니다.
- 이 앱은 실제 갤럭시 기기에서 시험해 보지 못한 상태로 배포됩니다. 문제가 있으면 상태 문구나 화면을 알려 주세요.

## 개발자용

```bash
cd android_app
./gradlew assembleRelease                         # whisper.cpp 포함 전체 빌드 (NDK 27, CMake 3.22 자동 설치)
./gradlew testDebugUnitTest -Pkosub.native=false  # JVM 단위 테스트
./gradlew assembleDebug -Pkosub.native=false      # 네이티브 없이 Kotlin만 빌드 (음성 인식 불가)
```

- 저장소에 들어 있는 `keystore/debug.keystore`로 서명합니다(덮어 설치가 되도록 항상 같은 키 사용). Play 스토어에 올리려면 별도 키로 서명해야 합니다.
- whisper.cpp는 빌드할 때 `app/src/main/cpp/CMakeLists.txt`에서 GitHub의 고정된 태그로 받아 옵니다.

```
app/src/main/java/com/kosub/player/
├── core/      자막 형식·문장 분할·처리 구간·작업 상태·번역기 (데스크톱 앱 로직을 Kotlin으로 이식)
├── engine/    자막 생성 엔진 (재생 위치 우선 처리, 번역, 자동 저장)
├── asr/       whisper.cpp JNI 연결, 모델 내려받기
├── media/     MediaCodec 오디오 구간 디코딩, 16 kHz 리샘플링
├── storage/   자막 파일 저장(SAF/MediaStore), 작업 기록, 파일 지문
└── ui/        홈, 재생 화면(Media3 ExoPlayer), 자막 목록, 설정
app/src/main/cpp/whisper_jni.cpp   whisper.cpp ↔ Kotlin
```
