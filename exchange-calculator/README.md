# 환율 계산기 (Galaxy S25용 안드로이드 앱)

계산기 키패드가 달린 다중 통화 환율 변환기입니다. 카메라로 가격표를 비추면 바로 환산해 주는 가격 스캐너도 들어 있습니다.

## 기능

| 화면 | 내용 |
|---|---|
| **변환기** | 최대 12개 통화를 동시에 환산합니다. 행을 누르면 그 통화가 입력 대상이 되고, `+ − × ÷` 계산도 됩니다(예: `1,250,000+380,000×2`). 금액을 길게 누르면 복사됩니다. |
| **키패드** | `C` 전체 지우기, `⟳` 환율 새로고침, `⌫` 한 글자 지우기(길게 누르면 전체 지우기). 위쪽 손잡이를 탭하거나 끌면 키패드를 접고 펼칩니다. 누를 때마다 진동합니다. |
| **통화 관리** | 통화 추가·삭제, `≡` 를 끌어서 순서 변경. 각 행의 `▼` 를 누르면 그 자리의 통화를 바로 바꿀 수 있습니다(한글·코드 검색 지원). |
| **가격 스캐너** | 카메라로 가격표를 비추면 숫자를 인식해 환산 금액을 원래 가격 위에 겹쳐 보여줍니다. `35.000đ`, `35k`, `1,234.56`, `1.234,56`, `3 500 000` 같은 표기를 처리합니다. ⏸ 로 화면을 고정하고, 라벨을 누르면 변환기로 보냅니다. 플래시도 켤 수 있습니다. 문자 인식은 기기 안에서만 처리합니다(ML Kit 내장 모델). |

환율은 **키가 필요 없는 무료 API**에서 받아옵니다. 1순위는 [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free)이고, 실패하면 [fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api)를 씁니다. 둘 다 하루 1회 갱신되는 기준 환율입니다. 마지막으로 받은 환율을 저장해 두므로 **오프라인에서도 계산**할 수 있습니다. 앱을 켜거나 다시 열 때 30분이 넘었으면 자동으로 갱신합니다.

> 은행·환전소에서 실제로 적용되는 환율(수수료 포함)과는 다를 수 있으니 참고용으로 써주세요.

## 갤럭시 S25에 설치하기

1. 폰에서 `dist/fxcalc-1.0.apk` 를 내려받습니다.
2. **자동 차단 끄기**(One UI 6 이상에서는 기본으로 켜져 있음):
   `설정 → 보안 및 개인정보 보호 → 자동 차단 → 끔`
3. 내려받은 APK를 엽니다. "출처를 알 수 없는 앱" 안내가 나오면 그 앱(내 파일 / Chrome 등)에 **이 출처 허용**을 켜고 설치합니다.
4. 설치가 끝나면 자동 차단은 다시 켜도 됩니다.

- Play 프로텍트가 "알 수 없는 앱"이라고 경고하면 **무시하고 설치**를 선택하면 됩니다. 직접 빌드해서 스토어에 등록하지 않은 앱이라 나오는 안내입니다.
- 이 APK는 빌드 PC의 디버그 키로 서명돼 있습니다. 다른 PC에서 새로 빌드한 APK로 업데이트하려면 기존 앱을 먼저 삭제해야 합니다.

## 직접 빌드하기

필요한 것: JDK 17 이상, Android SDK(platform 35, build-tools 35)

```bash
cd exchange-calculator
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease          # → app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest        # 단위 테스트 + 화면 스크린샷(app/screenshots/)
```

## 구성

- Kotlin 2.0, Jetpack Compose (Material 3), minSdk 26 / targetSdk 35, arm64 전용 빌드
- CameraX + ML Kit Text Recognition(라틴 문자, 모델 내장)
- `calc/` 계산기 엔진, 금액 표시 형식, 가격 문자열 파서(순수 Kotlin, 단위 테스트 포함)
- `data/` 환율 API, 기기 저장, 통화 이름(한국어)과 국기
- `ui/` 화면(변환기, 키패드, 통화 선택, 통화 관리, 가격 스캐너)
